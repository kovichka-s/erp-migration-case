# 34. Impact Analysis (for CR-001)

## Мета документа

Impact Analysis (Аналіз впливу) проводить комплексне оцінювання наслідків ухвалення Запиту на зміну (Change Request CR-001) для проекту міграції на Odoo ERP. Документ аналізує вплив на архітектуру Odoo, супутні артефакти вимог, бюджет, строки (Schedule) та ризики.

---

# Пов'язані артефакти

- [05. Scope Definition](05_Scope_Definition.md) — оцінка розширення меж
- [11. Business Rules](11_Business_Rules.md) — додавання нового правила BR-012
- [17. Requirements Traceability Matrix](17_Requirements_Traceability_Matrix.md) — оновлення трасування
- [23. Risk Analysis and Assumptions](23_Risk_Analysis_and_Assumptions.md) — аналіз нових ризиків
- [33. Change Request](33_Change_Request.md) — вхідний запит CR-001

---

# Комплексний аналіз впливу за 5 вимірами

| Напрям аналізу | Оцінка впливу | Детальний опис та висновки |
| --- | --- | --- |
| **1. Вплив на Scope та вимоги** | **Minor (Мінімальний)** | Розширює вимогу **FR-010** (Контроль наявності пакування) та додає нове бізнес-правило **BR-012** (Мінімальний пороговий залишок упаковки = 15 Big Bags). Поточний базовий Scope не порушується. |
| **2. Вплив на технічну архітектуру Odoo** | **Zero / Low (Без кастомізації)** | Реалізується через **стандартний механізм Odoo Reordering Rules (Min/Max rules)** у модулі Odoo Inventory без написання кастомного Python-коду. Використовується стандартний сервер сповіщень. |
| **3. Вплив на графік (Schedule)** | **Minor (+1 день)** | Потребує 8 годин конфігурації та 3 години QA-тестування. Завдання додається до Спринту 2 як PBI-13 (2 SP) без зміщення підсумкової дати Go-Live. |
| **4. Вплив на бюджет та ресурси** | **Negligible (Незначний)** | Оціночна вартість додаткових 11 людино-годин становить менше 1.5% від резерву незапланованих витрат (Contingency Buffer) проекту. |
| **5. Вплив на бізнес-ризики** | **Highly Positive (Знижує ризик)** | **Знижує рівень ризику R-02** (Нестача пакувальних матеріалів) із *High* до *Low*, гарантуючи безперервність роботи виробництва пелет. |

# Оновлення пов'язаних артефактів проекту

При затвердженні CR-001 підлягають автоматичному оновленню такі документи:

1. **`11_Business_Rules.md`:** додається правило `BR-012` (Автоматичний сигнал тривоги при залишку Big Bags < 15 шт.).
2. **`17_Requirements_Traceability_Matrix.md`:** додається вимога `FR-010.1` та зв'язок із новим PBI-13 у Спринті 2.
3. **`23_Risk_Analysis_and_Assumptions.md`:** оновлюється статус плану реагування для ризику `R-02`.
4. **`24_Decision_Log.md`:** додається прийняте рішення `DL-09` про підтримку Reordering Rules для пакування.
