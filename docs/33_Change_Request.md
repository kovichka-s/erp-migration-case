# 33. Change Request (CR-001)

## Мета документа

Change Request (Запит на зміну) фіксує формальне звернення стейкхолдерів щодо внесення змін до погодженогоScope, бізнес-правил чи функціональних вимог проекту міграції на Odoo ERP після завершення фази Discovery. Документ забезпечує контроль Scope Creep.

# Обґрунтування та опис зміни

### Опис поточної ситуації (Baseline)
У поточних вимогах (FR-010, BR-009) система відображає залишки пакувальних матеріалів (Big Bags) у модулі Odoo Inventory, але не генерує автоматичних попереджень (Alerts) для відділу закупівель при наближенні до критичного мінімуму.

### Пропонована зміна
Додати автоматичний індикатор та електронне сповіщення (Activity/Email) Менеджеру із закупівель, коли залишок порожніх Big Bags на складі опускається нижче порогового значення **15 шт.** (еквівалент менше 1 машино-відвантаження).

### Бізнес-обґрунтування (Business Justification)
Під час UAT-тестування виявлено ризик зупинки лінії пакування пелет через затримку постачання Big Bags від постачальника (lead time постачальника становить 3 дні). Відсутність упаковки унеможливлює відвантаження навіть за наявності готової сировини.
