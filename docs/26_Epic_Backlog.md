# 26. Epic Backlog

## Мета документа

Epic Backlog декомпозує високорівневий Scope проекту міграції на Odoo ERP (модуль прогнозування та продажу пелет) на логічні Епіки (Epics). Документ забезпечує зв'язок між концептуальними межами проекту (Scope Definition), функціональними вимогами (Functional Requirements) та подальшим Product Backlog.

# Деталізація Епіків

## EPIC-01: Складський облік та прозорість залишків

- **Бізнес-мета:** Ліквідувати інформаційний вакуум щодо складських залишків пелет та біг-бегів, виключивши телефонні дзвінки на склад.
- **Очікуваний результат:** Відбраження фактичної кількості готових Big Bags, зарезервованого обсягу та складського запасу пакування в Odoo Inventory.
- **Включені User Stories:** US-01, US-02, US-05.
- **Критерії успіху (KPI):** KPI-04 (Заповнення складу), KPI-05 (Контроль дефіциту пакування), KPI-10 (Точність складських даних).

## EPIC-02: Оцінка готовності та розрахунок накопичення пелет

- **Бізнес-мета:** Забезпечити розрахунок орієнтовної дати формування мінімальної партії пелет без використання складних AI/історичних моделей на першому етапі.
- **Очікуваний результат:** Модуль Odoo MRP розраховує орієнтовний час готовності партії на основі плану виробництва основної продукції (меблевого щита/дошки) та доступної потужності лінії пелетування.
- **Включені User Stories:** US-01, US-04.
- **Критерії успіху (KPI):** KPI-01 (Точність розрахунку готовності), KPI-06 (Використання відходів).

## EPIC-03: Управління замовленнями та інформування продажів

- **Бізнес-мета:** Прискорити відповідь клієнту щодо наявності продукції та дозволити формування замовлень лише при підтвердженій або очікуваній доступності.
- **Очікуваний результат:** Автоматичне сповіщення менеджера з продажу при досягненні готового залишку ≥ 10 Big Bags та фіксація замовлень у статусній моделі Odoo Sales.
- **Включені User Stories:** US-01, US-03, US-06.
- **Критерії успіху (KPI):** KPI-02 (Час відповіді клієнту), KPI-03 (Виконання вчасно), KPI-07 (Втрачені продажі).

## EPIC-04: Планування відвантажень та транспортна логістика

- **Бізнес-мета:** Оптимізувати транспортні витрати шляхом відвантаження економічно обґрунтованих партій (від 10 до 22 Big Bags).
- **Очікуваний результат:** Розрахунок ваги/об'єму в Odoo при формуванні заявки на доставку та координація роботи логіста й складача.
- **Включені User Stories:** US-03, US-06.
- **Критерії успіху (KPI):** KPI-08 (Завантаження транспорту), KPI-09 (Тривалість циклу замовлення).

## EPIC-05: Управлінська аналітика та KPI Dashboards

- **Бізнес-мета:** Надати власникові компанії та керівникам підрозділів інструмент для прийняття рішень на основі об'єктивних даних.
- **Очікуваний результат:** Звіти та дашборди в Odoo з можливістю відстеження заповнення складу, швидкості виробництва пелет та історії змін.
- **Включені User Stories:** US-07.
- **Критерії успіху (KPI):** Повне покриття метрик KPI-01 — KPI-10.
