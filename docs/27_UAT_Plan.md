# 27. User Acceptance Testing (UAT) Plan

## Мета документа

План прийомального тестування користувачами (User Acceptance Testing Plan) визначає стратегію, тестові сценарії, відповідальні ролі, середовище та критерії успішного прийняття бізнесом функціональності Релізу 1 Odoo ERP (модуль продажу та оцінки готовності пелет).

# Учасники тестування (UAT Roles)

| Роль | Представник бізнесу | Сфера відповідальності в UAT |
| --- | --- | --- |
| **Business Owner** | Власник підприємства / Керівник продажів | Фінальне підписання протоколу UAT та дозвіл на запуск (Go-Live). |
| **Key User (Sales)** | Менеджер з продажу | Перевірка відображення залишків, розрахункової дати готовності та оформлення замовлень. |
| **SME (Warehouse)** | Керівник складу пелет | Перевірка точності залишків продукції, Big Bags та тригерів сповіщень. |
| **BA / Test Lead** | Бізнес-аналітик | Фасилітація UAT, фіксація дефектів, допомога користувачам. |

# Вхідні та вихідні критерії UAT (Entry & Exit Criteria)

### Вхідні критерії (Entry Criteria)
1. Завершено розробку PBI-01 — PBI-06 та виконано всі технічні пункти DoD (unit-тести, code review).
2. Система розгорнута на середовищі **UAT Staging Environment** із завантаженими тестовими даними з «1С».
3. Підготовлено інструкції та проведені первинні інструктажі для учасників UAT.

### Вихідні критерії (Exit Criteria)
1. 100% критичних тестових сценаріїв (UAT-01 — UAT-04) виконано зі статусом **Passed**.
2. Відсутні блокуючі (Blocker) та критичні (Critical) дефекти у дефект-логу.
3. Протокол UAT підписано Керівником відділу продажів та Власником компанії.

# Тестові сценарії UAT (Gherkin Format)

## UAT-01: Перевірка складського залишку пелет та Big Bags

- **Пов'язано з:** AC-01, AC-05, PBI-01, PBI-02
- **Сценарій:**
  ```gherkin
  GIVEN Керівник складу оприбуткував 15 готових Big Bags у модулі Odoo Inventory
  AND поточний залишок пакувальних тари становить 50 порожніх Big Bags
  WHEN Менеджер з продажу відкриває дашборд залишків
  THEN система відображає точно 15 доступних Big Bags готових пелет
  AND показує залишок 50 порожніх Big Bags із зеленим статусом забезпечення.
  ```

## UAT-02: Перевірка спрощеного розрахунку дати готовності партії

- **Пов'язано з:** AC-01, AC-06, PBI-03, BR-010
- **Сценарій:**
  ```gherkin
  GIVEN Поточний залишок готових пелет становить 4 Big Bags (менше мін. партії 10 Big Bags)
  AND планова потужність лінії виробництва становить 3 Big Bags/день
  WHEN Менеджер з продажу переглядає картку готовності партії
  THEN система розраховує потребу в 6 Big Bags
  AND відображає орієнтовну розрахункову дату готовності через 2 дні від поточної дати.
  ```

## UAT-03: Тригерне сповіщення та створення замовлення

- **Пов'язано з:** AC-03, AC-07, PBI-04, PBI-05
- **Сценарій:**
  ```gherkin
  GIVEN Залишок готових пелет досяг 10 Big Bags
  WHEN Система фіксує досягнення порогового значення
  THEN Менеджер з продажу отримує автоматичне сповіщення в Odoo
  AND має можливість у 1 клік створити Замовлення Покупця на 10 Big Bags.
  ```

## UAT-04: Обмеження доступу за ролями (Security Check)

- **Пов'язано з:** NFR-003, PBI-06
- **Сценарій:**
  ```gherkin
  GIVEN Менеджер з продажу авторизувався в Odoo під своїм обліковим записом
  WHEN Він намагається змінити налаштування специфікації складу (BOM) чи коригувати собівартість
  THEN система блокує операцію та відображає повідомлення про відсутність прав доступу.
  ```
